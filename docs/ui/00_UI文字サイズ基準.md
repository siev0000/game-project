# UI文字サイズ基準

このプロジェクトでは、通常の本文、設定値、操作ボタン、変更内容、説明文を `15px` 基準とする。

- 通常本文・入力・ボタン・説明: 15px以上
- 補助説明・サブ情報: 13px
- コード、ID、装飾ラベルなど重要度の低い情報: 11px以上
- 11px未満は、読まなくても操作や判断に影響しない純粋な装飾に限る

新規画面では `src/css/typography.css` の以下の変数を使用する。

```css
var(--ui-font-size-body)
var(--ui-font-size-control)
var(--ui-font-size-secondary)
var(--ui-font-size-micro)
```

既存画面を変更する場合も、変更対象内の重要な文字が11px以下になっていないか確認する。
