# 2Dボーン編集 名称メモ v1

対象画面: `2d_bone_editor_split/`

## 目的

画面上で重なって見える「ボーン」「画像」「枠」「メッシュ」を区別するための共通名称です。

2Dボーン編集に関する相談・実装・調査を始める前に、このメモを確認します。ここにない言い方や複数の意味に取れる言い方が出た場合は、変更前に対象を確認します。

## 今回確定した重要な区別

### リサイズ枠

- 通常編集画面で、選択中ボーンを囲む青い四角形です。
- 四隅に水色の四角い操作点があります。
- 通常時はボーンのW/Hを変更するために使います。
- 「ボーン表示サイズだけ調整」がONの場合は、編集用表示枠だけを変更します。
- DOM上では主に `#resizeBox`、四隅は `.resize-handle` です。

### メッシュ描画幅

- 連続メッシュ画像がキャラクター上へ描画されるときの太さです。
- ボーンのWとメッシュ設定の「ボーン側の太さ」から計算されます。
- `targetWidthScale` や `getMeshTargetPoints()` が関係します。
- リサイズ枠とは別物です。

### 連続メッシュ対象のボーン実W

連続メッシュの `boneChain` に含まれる各ボーンの数値Wは、チェーン内の共通値として扱います。腰・胸・首のいずれかでW数値を変更すると、全モーションコマを含む対象ボーンの実Wが同じ値になります。「ボーン表示サイズだけ調整」の表示Wは別の共通値です。

通常画面の四隅ハンドルは、下記の画像変形へ変更したため、連続メッシュ対象の実W/Hを変更しません。

### 連続メッシュ画像の四隅変形

- 通常編集で連続メッシュ対象ボーンを選択した場合、青いリサイズ枠はそのボーン区間に実際に描画される画像端を示します。
- 水色の四隅ハンドルは、対応する画像端の片側幅を変更し、画像そのものを変形します。
- 左右は独立して変更できるため、長方形の片側だけを広げて台形にできます。
- 親子区間の境界は同じ断面を共有し、片方を広げても画像の継ぎ目を離しません。
- この四隅操作ではボーンの実W/Hは変えません。実W/Hは数値入力、「ボーン表示サイズだけ調整」は従来どおり別に扱います。

### 手画像の差し替え

- 右手・左手ボーンへ、開いた手・握った手などの画像候補を個別登録します。
- 使用する手画像はモーションの各コマで選択し、未指定のコマは通常の手画像を表示します。
- 差し替え画像は同じ手ボーンの位置・回転へ追従し、画像X/Y・拡大・回転・反転・部位分割を候補ごとに保持します。
- 内部データは既存互換のため `layer.morphs` とコマ側 `pose.morphId` を使いますが、手ボーンの画面表示では「モーフ」ではなく「手画像」と呼びます。
- 持ち物は手画像へ含めず、別処理とします。

## 画面上の名称

| 名称 | 画面上の見た目 | 役割・変更対象 | 主なコード・データ |
|---|---|---|---|
| ボーン本体 | 色付きのひし形。頭側が太く尾側が細い | 選択、移動、回転のクリック対象 | `.bone-overlay-item polygon` |
| ボーン輪郭 | ボーン本体の外周線 | 通常1px、選択中だけ少し太く表示 | ボーンSVGのstroke |
| リサイズ枠 | 選択対象を囲む青い四角形 | 通常画像はW/H、連続メッシュは画像端、表示調整中は表示W/Hを示す | `#resizeBox` |
| リサイズハンドル | リサイズ枠の四隅にある水色の四角 | 通常画像は対角固定サイズ変更、連続メッシュは画像端の片側幅変更 | `.resize-handle` |
| ボーン表示サイズ | 編集しやすくするためのボーン本体と枠の表示寸法 | 画像・メッシュ・実W/Hは変更しない | `editorBoneDisplayW/H` |
| ボーンの実サイズ | 通常のリサイズ枠で変更するW/H | ボーン座標系と画像配置の基準 | 各poseの `w/h` |
| ボーン頭 | ボーンの親側・根元側の点 | 親の接続点と重ねる | `headX/headY` |
| ボーン尾 | ボーンの子側・先端側の点 | 子ボーンの頭を接続する | `tailX/tailY` |
| 回転軸 | 橙のひし形 | ボーン回転の中心 | `ox/oy` |
| 親側接続点 | 青い丸 | 親画像内の接続位置 | `attachX/attachY` |
| 画像 | ボーンへ貼り付けたキャラクター素材 | 見た目。ボーン本体とは別レイヤー | `.image-transform` |
| 画像範囲 | 部位分割画面で元画像から切り取る矩形 | その部位が参照する元画像範囲 | `imageCropX/Y/W/H` |
| 連続メッシュ | 複数の親子ボーンへ1枚の画像を曲げて貼る機能 | 腕、脚、胴体などを連続変形 | `meshBindings[*]` |
| メッシュ対象ボーン列 | 連続メッシュ設定の開始→終了 | メッシュが追従するボーン一覧 | `boneChain` |
| メッシュ範囲 | 連続メッシュ編集画面のシアン枠 | 元画像内で滑らかに変形する対象範囲 | `sourceRect` |
| メッシュ中心線 | 元画像上の緑系の線 | 画像の中心とボーン列の対応 | `controlPoints` |
| メッシュ分割点 | 中心線上の丸点 | 肘・膝などの対応位置と左右幅 | `controlPoints[*]` |
| メッシュ左右幅 | 各分割点から左右端までの範囲 | 元画像側の取り込み幅 | `leftWidth/rightWidth` |
| メッシュ描画幅 | キャラクターへ貼った結果の太さ | ボーンWに対する表示倍率 | `targetWidthScale` |
| メッシュ変形対象範囲 | 関節の変形範囲として指定する矩形 | 滑らかに歪ませる範囲だけを限定 | `sourceRect` と描画処理 |

## やり取りの確認ルール

- 「枠」と言われた場合は、リサイズ枠・画像範囲・メッシュ範囲のどれかを確認します。
- 「幅」と言われた場合は、ボーン実W・リサイズ枠・画像範囲・メッシュ左右幅・メッシュ描画幅のどれかを確認します。
- 「ボーンの骨部分」は色付きのひし形である「ボーン本体」を指します。
- 「青い枠」は、通常画面ならリサイズ枠、連続メッシュ編集画面ならメッシュ変形対象範囲です。画面名も合わせて判断します。
- 意味を確定できない場合、コードを変更する前に「どの画面の、何色・何形の部分か」を短く確認します。

## 変更履歴

- v1: リサイズ枠とメッシュ描画幅を取り違えたため作成。「メッシュで指定されたボーンの幅」は、対象ボーンのリサイズ枠の横幅として確定。
- v1追記: 胸・腹・腰のような同一メッシュ対象では、通常編集の実Wと「ボーン表示サイズだけ調整」の表示Wを、それぞれチェーン内の共通値として固定する仕様を明記。
- v1追記: 通常2Dの新規デフォルト胴体は「腰→胸→首」とし、腹は既存JSON互換のため読込対応だけ残す。共通横リサイズは全対象の反対辺を固定して同じ方向へ伸縮する。
- v1追記: 連続メッシュ対象の通常リサイズ枠は実際の画像端へ接続し、四隅で左右の描画幅を独立変更する。共有断面は隣接区間へ引き継いで継ぎ目を維持する。
- v1追記: 右手・左手では画像候補を直接追加し、コマごとに通常の手または登録した手画像を選択する。持ち物は対象外。
