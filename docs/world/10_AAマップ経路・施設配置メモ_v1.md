# AAマップ経路・施設配置メモ v1

## 1. このメモの扱い

このメモは、《アポクリファ＝アーカイブ》内部の施設配置と、施設へ到達するための道路・通路・リフト・貨物路を記録する。

船体形状、階層区分、既存施設名は次のメモを基準とする。

- `09_AAマップ構造・船体形状メモ_v6.md`

本メモでは、施設同士が隣接しているだけでは移動可能とみなさない。

```text
施設A
→ 施設Aの出入口
→ 接続通路
→ 幹線道路または環状路
→ 目的施設の取付道路
→ 施設Bの出入口
→ 施設B
```

座標が近くても、道路・通路・ゲートが登録されていなければ直接移動できない。

---

## 2. 確定事項と初期配置

### 確定事項

- 船体は全長4,000m・最大幅2,500m
- 各正式階層のターミナル中心を `(0,0)` とする
- X正方向は船首、X負方向は船尾
- Y正方向は右舷、Y負方向は左舷
- 上層・中層・下層の一般移動は中央ターミナル塔を使う
- 上層ターミナルと底部外征区は外征用直通リフトで接続する
- 施設間の移動は道路・通路・リフトなどを経由する
- 上層は中央共有区、マギテック側、エイドロン側に分かれる

### 本メモで採用する初期配置

上層は左右舷方向に二分する。

```text
左舷側（Y負方向）：マギテック側区画
右舷側（Y正方向）：エイドロン側区画
中央帯（Y=-250～+250m）：中央共有区
```

この左右配置は、施設面積を確定する段階で入れ替えることができる。
道路構造は左右を反転しても成立する。

### 中央ターミナル塔の初期寸法

```yaml
central_terminal_tower:
  center: [0, 0]
  shape: circle
  radius_m: 250
  status: initial
```

各階層では、塔の外周にターミナルコンコースを置く。

```yaml
terminal_concourse:
  inner_radius_m: 250
  outer_radius_m: 330
```

## 4. 中央ターミナル塔の縦方向接続

### 4.1 一般移動系統

```text
上層ターミナル
      ↕ 一般リフト群
中層ターミナル
      ↕ 一般リフト群
下層ターミナル
```

一般リフトは、各階層のターミナル以外には停止しない。

### 4.2 貨物移動系統

```text
上層共通物流区
      ↕ 貨物リフト
中層貨物検査区
      ↕ 貨物リフト
下層物流・再生資源区
      ↕ 貨物リフト
底部外征区貨物庫
```

貨物系統は旅客コンコースを通らない。

### 4.3 外征移動系統

```text
上層ターミナル
      ↕ 外征用直通リフト
底部外征区
```

- 中層・秘匿中層・下層には停止しない
- 秘匿中層に扉を持たない
- 中央塔の外周側を独立して通る
- 出撃用と帰還用を別シャフトにできる

### 4.4 非常用系統

```text
上層非常通路
      ↕
中層非常通路
      ↕
下層非常通路
```

通常時は閉鎖され、避難・救助・整備時のみ使用する。

# 10. 共通施設の配置方法

小規模な共通施設は、単独の大地区ではなく、各主要地区の内部または道路沿いに配置する。

## 10.1 上層

- 充電・燃料供給：両居住区と各研究環状路
- 洗浄・整備・医療：両居住区の中央幹線寄り
- 市場・交流・娯楽：各居住区とマイオスフィールド
- 重傷個体停止保管：各側の医療施設奥
- 警備所：認証門、試験場、高機密保管区
- 汚染検査所：エイドロン試料保管区、貨物トンネル出口
- 避難所：中央共有区と両居住区
- 予備動力：各区画の外周整備区
- 通信・案内・U-WEA端末：幹線道路と環状路の交差点

## 10.2 中層

- 充電・洗浄・市場・娯楽：コアシェルタウン
- 整備・医療・装備改修：リファインバレー
- 内部診断・人格異常検査：ターミナルと医療区の間
- 倉庫：レジストリンク・ドーム、工業貨物幹線
- 汚染検査：貨物検査区とアルボラ入口
- 避難所：中央環状路沿い
- 予備動力：コアシェル外周、燃料工場
- 通信・案内・固定掲示板：ターミナル、ドーム、主要交差点

## 10.3 下層

- 充電・水・洗浄・市場：ラストハブ
- 整備・医療：ラストハブ外周、重機整備区
- 重傷個体停止保管：ラストハブ医療区
- 汚染検査：危険区入口、マテリアル・ホロー出口
- 避難所：ラストハブと非常迂回環状路
- 予備動力：リクレイムベルト、バイオリアクター、船尾機関区
- 警備所：S9入口、特別隔離区、外部資源吸収設備
- 案内端末：一般区域のみ
- 危険区内の案内は作業認証端末に限定

温度・湿度調整、隔壁制御、空気・排水・電力設備は分散インフラであり、単一の地図施設としては扱わない。

# 12. 現段階で未確定の項目

- 各施設の建物形状
- 建物内の階数と内部通路
- 道路の高低差
- 橋、立体交差、トンネルの正確な位置
- 輸送ポッド駅の数
- 上層左右区画を入れ替えるか
- 秘匿中層への正規進入路
- 底部外征区の発着口数
- 空中艦の正式な艦級名と格納数
- 各道路の速度制限
- 非常時の閉鎖順序
- 事件後施設の座標

この初期配置を基準に、次版では各施設の面積と出入口位置を調整し、道路同士の交差点、駅、隔壁、検問所を確定する。
