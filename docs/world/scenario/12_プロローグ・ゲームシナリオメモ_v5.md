# プロローグ・ゲームシナリオメモ v5

会話と短い情景描写を中心に記載する。
プレイヤー操作、移動、調査、戦闘、強制イベントが入る箇所のみ、ゲーム進行用の指示を別枠で挟む。

台詞は `09_世代別会話・発話ルール.md` に従う。

第二世代は精密電子機器、通信、射撃、索敵、測量に優れ、センサー性能は第三世代より高い。
第三世代主人公は第二世代が取得・共有した情報を受け取り、複数の装備や現地設備を組み合わせて任務全体を処理する。

## 支援電子AIの情報処理範囲

- 支援電子AIは、現場を自分の感覚で直接見ることはできない。
- 第二世代などの実働個体が送信した観測情報、各機の自己診断、施設センサー、任務ログだけを受け取る。
- 複数の報告を整理・照合し、必要な個体へ警告、状況、指示、過去データを伝達する。
- 現場の異常へ最初に気づくのは、原則としてセンサー性能に優れた第二世代である。
- 支援電子AIは、その報告を受信して全体へ伝達する情報管制役であり、自ら異常を発見したようには描写しない。
