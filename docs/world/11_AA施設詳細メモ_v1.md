# AA施設詳細メモ v1

## 1. このメモの目的

このメモは、《アポクリファ＝アーカイブ》（AA）に存在する各地区・施設について、次の情報を具体化する。

- 施設の役割
- 利用者
- 内部構造
- 主な設備
- 搬入物と搬出物
- 管理権限
- 危険性と緊急対応
- 他施設との機能的な関係
- 本編事件当時と事件後の違い

位置・座標・占有寸法・道路経路は、次のメモを正本とする。

- `10_AAマップ経路・施設配置メモ_v1.md`

船体形状・階層構造・施設名一覧は、次のメモを正本とする。

- `09_AAマップ構造・船体形状メモ_v6.md`

このメモでは座標を重複記載しない。
施設を移動しても、役割と内部構造の説明は原則として変わらない。

---

## 2. 設定の扱い

### 2.1 施設種別

```yaml
district:
  複数の建物・設備・道路を含む地区

facility:
  単独の建物または独立設備

embedded_facility:
  別施設の内部または敷地内に組み込まれた設備

infrastructure:
  配管、電力、通信、空調、輸送などの分散設備
```

地区の面積と内部施設の面積は重ねて計上する。
内部施設は地区の外に追加されるものではない。

### 2.2 確定度

```yaml
confirmed:
  既存設定または今回の構造として確定

structured:
  既存の役割から具体化した内部構造案

provisional:
  名称、規模、詳細方式が未確定

post_incident:
  第4・第5世代事件後に成立または改称
```

### 2.3 時代上の注意

本編事件当時、セレス・ゼロとΩセレスはまだ存在しない。

そのため、次の名称・制度は原則として事件後に扱う。

- セレス直属・統合兵装開発区
- セレスティア規格
- セレス監査官
- ゼロアーカイブ
- Ωセレス向け正式更新設備
- Ωシリーズ専用兵装ライン

本編事件当時の上層は、共同管理機構、マギテック上位個体、エイドロン上位個体が使用する。

# 3. 全階層共通施設

## 3.1 ターミナル

```yaml
type: facility
status: confirmed
```

### 役割

各階層の中央交通拠点。
中央ターミナル塔のリフト群と、階層内道路・通路を接続する。

ターミナルは目的施設へ直接つながる転送装置ではない。
利用者はターミナル到着後、階層内の道路、歩行通路、輸送ポッド、貨物路を使って移動する。

### 内部構造

```text
中央リフト群
├ 一般乗降ホール
├ 大型機乗降ホール
├ 警備・認証区
├ 案内・地図区
├ 待機広場
├ 荷物一時預かり区
├ 緊急避難区
└ ターミナルコンコース
```

### 主な設備

- 一般リフト
- 大型機用リフト
- 貨物リフトへの管理接続
- 階層案内端末
- 固定掲示板
- U-WEA系電子AI接続端末
- 住民・任務個体の認証装置
- 汚染・危険物の簡易検査装置
- 隔壁・防火シャッター
- 緊急充電設備
- 救護・応急修理区

### 管理

- 通常時：共同管理機構と各階層の交通担当
- 高警戒時：警備担当が通行権限を制限
- 事件後：セレス・ゼロ系管理網が監督可能

---

## 3.2 居住・休止区

```yaml
type: district
status: confirmed
```

### 役割

機械生命が活動停止、充電、整備、交流を行う生活地区。
すべての階層に存在するが、設備品質と文化が異なる。

### 内部構造

```text
居住・休止区
├ 個体用休止室
├ 共同充電区
├ 燃料・水・空気供給所
├ 洗浄区
├ 軽整備所
├ 共有ラウンジ
├ 小規模市場
├ 掲示板・通信所
├ 重傷個体停止保管区
└ 避難区画
```

### 階層差

- 上層：高品質、静音、個別調整が多い
- 中層：最も人口が多く、商業・交流機能が発達
- 下層：中古部品、共同設備、現地修理が中心

### 内部構造

```text

├ 外装洗浄・除染
├ 損傷診断
├ 応急修理
├ 部品交換
├ 内部回路・動力診断
├ 腐食・侵食除去
├ 人格・記憶検査
├ 長期停止保管
└ 復帰確認区
```

### 注意

グロウメタ汚染が疑われる場合、通常修理区へ入れず、隔離検査へ送る。

- AA全域への無制限な直接操作
