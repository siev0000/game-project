# 外界マップ画像素材制作仕様 v1

## 1. このメモの目的

横スクロール探索で使用する外界マップ画像を制作するときの、必要素材、画像寸法、透過、基準位置、命名規則をまとめる。

対象地形は次の12種類。

1. 草原
2. 森
3. 湿地
4. 海岸
5. 砂漠・荒野
6. 雪原・氷雪地
7. 山岳
8. 渓谷
9. 洞窟
10. 地下洞窟
11. 火山地帯
12. 遺跡

現在のマップは仮CSSで表示している。  
本メモの画像が揃った後、画像読み込みとマップチップ配置処理を実装する。

---

## 2. 現在のゲーム内基準

現在の探索マップは、次の論理サイズを基準にしている。

| 項目 | 現在値 |
|---|---:|
| マップ設計高さ | 720px |
| 標準地面Y座標 | 570px |
| 地面より上の表示領域 | 570px |
| 地面より下の表示領域 | 150px |
| 画面基準幅 | 720px |
| 外界エリア横幅 | 3,600～4,800px |
| 現在のプレイヤー表示枠 | 42×66px |
| プレイヤー移動速度 | 310px/秒 |

ブラウザ上では画面サイズに合わせて全体が縮小される。  
素材制作時はブラウザ上の見た目ではなく、上記の論理サイズを基準にする。

---

## 3. 最初に用意する最小セット

最初から12地形すべてを完成させず、まず「森」1エリア分を作って表示確認する。

### 森の確認用セット

- プレイヤー待機アニメーション
- プレイヤー歩行アニメーション
- 遠景背景
- 中景背景
- 前景背景
- 地面上端チップ
- 地面内部チップ
- 足場チップ
- 木2～3種類
- 岩2種類
- 草・茂み3～5種類
- 仮ランドマーク1種類

森で大きさ、色、キャラとの比率、スクロール速度を確定してから、他地形へ展開する。

## 4. 歩行キャラクター画像

### 4.1 基本寸法

| 項目 | 推奨値 |
|---|---:|
| 素材の1フレーム | 96×144px |
| ゲーム内表示 | 42×66px |
| キャラ本体が収まる目安 | 幅72～84px、高さ126～136px |
| 足元基準点 | X=48、Y=136 |
| 下側透明余白 | 8px |
| 画像形式 | PNG、透過背景 |

96×144px全体をキャラで埋めず、武器、髪、マント、上下動が枠外へ出ないように透明余白を残す。

全フレームで足元基準点を同じ位置にする。  
歩行中に上下動させる場合も、接地している足は原則としてY=136に合わせる。

```text
96px
┌────────────────┐
│   上側余白     │
│                │
│   キャラ本体   │ 144px
│                │
│       ●        │ ← 足元基準 X=48 / Y=136
└────────────────┘
        8px
```

### 4.2 必要アニメーション

| ファイル | フレーム数 | 画像全体サイズ | 再生目安 | 優先度 |
|---|---:|---:|---:|---|
| `player_idle.png` | 4 | 384×144px | 6fps | 必須 |
| `player_walk.png` | 8 | 768×144px | 10～12fps | 必須 |
| `player_talk.png` | 4 | 384×144px | 6fps | 推奨 |
| `player_interact.png` | 6 | 576×144px | 8～10fps | 後回し |
| `player_jump.png` | 6 | 576×144px | 状態連動 | 後回し |
| `player_fall.png` | 2 | 192×144px | 状態連動 | 後回し |

フレームは左から右へ並べる。  
すべて同じ96×144pxセルを使用する。

現在の実装は右向き画像を左右反転して左向きにする。  
左右で武器、義手、紋章、文字などが変わるキャラは、左向き画像も別ファイルで用意する。

```text
player_walk_right.png
player_walk_left.png
```

### 4.3 キャラ画像へ含めないもの

- 地面へ落ちる影
- 発光エフェクト
- 足元の砂煙
- 吹き出し
- 選択マーカー
- 当たり判定表示

影やエフェクトはゲーム側で重ねる。  
画像へ焼き込むと、地形や照明が変わったときに再利用しにくくなる。

### 4.4 当たり判定の目安

当たり判定は画像全体ではなく、胴体と足元に合わせる。

| 項目 | ゲーム内論理サイズ |
|---|---:|
| 表示枠 | 42×66px |
| 推奨当たり判定 | 幅26×高さ58px |
| 基準 | 表示枠の下中央 |

髪、帽子、マント、武器には通常の移動当たり判定を付けない。

## 5. NPC・敵キャラクター

NPCと人型敵は、原則としてプレイヤーと同じ規格にする。

| 種別 | 1フレーム推奨 | ゲーム内表示目安 |
|---|---:|---:|
| 小型 | 64×96px | 28×44px前後 |
| 標準人型 | 96×144px | 42×66px |
| 大型人型 | 144×192px | 64×88px前後 |
| 大型獣・横長 | 192×144px | 88×66px前後 |

サイズが違っても足元基準は下中央に統一する。

最低限必要な動作は次のとおり。

- 待機
- 歩行
- 会話または反応

戦闘をマップ上で行う場合は、後から攻撃、被弾、戦闘不能を追加する。

## 6. 背景画像

背景は1枚の巨大画像にせず、遠景・中景・前景の3層に分ける。

### 6.1 共通寸法

| レイヤー | 推奨制作サイズ | 透過 | 用途 |
|---|---:|---|---|
| 遠景 `far` | 1,440×720px | 不要 | 空、遠い山、地平線、洞窟奥 |
| 中景 `mid` | 1,440×720px | 必要 | 木、岩壁、建造物、近い山 |
| 前景 `foreground` | 1,440×720px | 必要 | 手前の草、枝、柱、霧 |

横方向へ繰り返しても継ぎ目が出ないようにする。  
左右端の色、高さ、形を接続する。

前景はキャラクターの一部を隠すことがあるため、画面全体を不透明にしない。

### 6.2 ファイル形式

- 不透明な遠景：WebP
- 透過する中景・前景：透過WebPまたはPNG
- 色空間：sRGB
- 画像内へ文字、UI、枠線を入れない

### 6.3 現在の背景ID

外界エリアは次のIDで背景を参照する。

```text
exterior_{terrain}_far
exterior_{terrain}_mid
exterior_{terrain}_foreground
```

森の場合は次の名前になる。

```text
exterior_forest_far.webp
exterior_forest_mid.webp
exterior_forest_foreground.webp
```

## 7. マップチップ

### 7.1 基本寸法

| 項目 | 寸法 |
|---|---:|
| 制作用マスターチップ | 128×128px |
| ゲーム内論理サイズ | 64×64px |
| 1マス | 64px |

制作画像は2倍解像度の128×128pxで作り、ゲーム内では64×64pxとして使用する。

ピクセルアートとして作る場合は64×64px原寸でもよい。  
同一地形内では制作倍率を混在させない。

### 7.2 地面用に必要なチップ

- 地面上端
- 地面内部
- 左端
- 右端
- 左上角
- 右上角
- 薄い足場
- 崖面
- 斜面上り
- 斜面下り
- 小さな段差
- 壊れる床

斜面チップは2マス幅を基本とする。

| 種類 | 制作サイズ | ゲーム内サイズ |
|---|---:|---:|
| 1マスチップ | 128×128px | 64×64px |
| 2マス斜面 | 256×128px | 128×64px |
| 大型崖面 | 256×256px | 128×128px |

### 7.3 画像と当たり判定

画像と当たり判定は別データにする。

- 草や枝が出ていても、地面上端の当たり判定は一定にする
- 洞窟の鍾乳石など、背景だけの物には当たり判定を付けない
- 前景画像だけで通路を塞がない
- 足場の接地面が画像から判断できるようにする

---

## 8. 配置物・ランドマーク

配置物は透過PNGまたは透過WebPで用意する。

| 種別 | 推奨制作サイズ | ゲーム内表示目安 |
|---|---:|---:|
| 草・小石・小物 | 128×128px | 64×64px以内 |
| 茂み・岩 | 256×256px | 128×128px以内 |
| 標準樹木 | 256×512px | 128×256px前後 |
| 巨木・大岩 | 512×768px | 256×384px前後 |
| 洞窟入口 | 768×768px | 384×384px前後 |
| 遺跡入口・門 | 768×768px | 384×384px前後 |
| 大型ランドマーク | 1,024×1,024px以内 | 個別設定 |

すべて足元または設置面が分かるようにする。  
木や柱は画像下中央、横長の岩は画像下辺中央を配置基準にする。

### 入口画像

施設入口、洞窟入口、地下への階段などは、通常の背景へ描き込まず独立画像にする。

これにより後から次の状態へ切り替えられる。

- 未発見
- 発見済み
- 封鎖中
- 開放済み
- イベント後に崩壊

## 9. 地形別の必要素材

| 地形 | 固有素材 |
|---|---|
| 草原 | 草地、丘、花、低木、風で動く草、遠い山 |
| 森 | 通常木、巨木、倒木、茂み、根、木漏れ日 |
| 湿地 | 浅瀬、泥、葦、浮草、枯木、霧 |
| 海岸 | 砂浜、岩礁、波打ち際、流木、海食洞 |
| 砂漠・荒野 | 砂丘、乾いた地面、岩柱、枯木、砂煙 |
| 雪原・氷雪地 | 雪面、氷、積雪岩、針葉樹、吹雪 |
| 山岳 | 岩肌、崖、尾根、山道、高山植物、雲 |
| 渓谷 | 谷底、断崖、川、橋、岩柱、滝 |
| 洞窟 | 洞窟壁、鍾乳石、岩棚、入口光、苔 |
| 地下洞窟 | 暗い岩壁、地底湖、発光鉱石、深い穴 |
| 火山地帯 | 黒い岩、溶岩、噴気孔、灰、熱気 |
| 遺跡 | 石床、崩れた壁、柱、門、像、旧文明装置 |

各地形で最低限必要な構成は次のとおり。

- 背景3層
- 地面チップ一式
- 足場2種類以上
- 小型配置物3種類以上
- 中型配置物2種類以上
- ランドマーク1種類

## 10. 推奨フォルダ構成

### 10.1 既存のロケーション画像について

`src/assets/images/locations/` には、次のような既存画像がある。

```text
平原.webp
大森林・中部.webp
獣の森.webp
獣の森・沼地.webp
海沿いの森.webp
砂漠山.webp
鉱脈入口.webp
大鉱山.webp
地下水路.webp
ロボット研究所_廃墟.webp
```

これらは地形の色、雰囲気、建築様式を決める参考画像として利用できる。

ただし現状では、遠景・中景・前景に分かれておらず、横方向の継ぎ目や接地面も保証されていない。  
そのまま横スクロール背景やマップチップとして完成扱いにはせず、参考資料または切り出し元として扱う。

## 11. 命名規則

半角英小文字とアンダースコアを使用する。

```text
用途_地形_種類_番号
```

例：

```text
bg_forest_far_01.webp
bg_forest_mid_01.webp
bg_forest_foreground_01.webp
tile_forest_ground_top_01.webp
tile_forest_ground_fill_01.webp
prop_forest_tree_01.webp
prop_forest_bush_03.webp
landmark_forest_ancient_tree_01.webp
entrance_cave_main_01.webp
```

連番は2桁に統一する。

## 12. 納品前チェック

### キャラクター

- [ ] 背景が透明
- [ ] 全フレームが同じセルサイズ
- [ ] 足元基準点が揃っている
- [ ] 最初と最後をつないでも不自然に跳ねない
- [ ] 左右反転して問題ない
- [ ] 影やUIが焼き込まれていない

### 背景

- [ ] 1,440×720px
- [ ] 左右へ繰り返しても継ぎ目がない
- [ ] 遠景・中景・前景が分かれている
- [ ] 中景・前景の透明部分が維持されている
- [ ] キャラクターが背景へ埋もれない明度差がある

### マップチップ・配置物

- [ ] 64px論理グリッドへ合わせられる
- [ ] 接地面が判断できる
- [ ] 余計な透明余白がない
- [ ] 同じ地形内で光源方向が揃っている
- [ ] ファイル名から用途と地形が分かる

## 13. 制作順

```text
1. 標準プレイヤーの待機・歩行
2. 森の背景3層
3. 森の地面・足場チップ
4. 森の木・岩・茂み
5. 森エリアへ仮実装して比率確認
6. キャラとチップの寸法を確定
7. 残り11地形へ展開
8. NPC・敵・入口・イベント用画像を追加
```

キャラと森の最小セットを先に確認し、寸法確定前に全地形を量産しない。
