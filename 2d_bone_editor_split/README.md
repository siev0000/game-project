# 2D Bone Motion Editor v34 - split version

v33 分割版を基準に機能追加した開発版です。

## ファイル
- `index.html` : 画面構造
- `style.css` : 見た目・レイアウト
- `app.js` : ボーン、フレーム、画像、保存などの処理
- `MEMO.md` : 現在の仕様、やること、今後の候補

## v34 主な変更
- BONE編集欄の通常ラベル色を `#cbd7e2` に調整
- 1枚の画像を複数ボーンで共有可能
- ボーンごとに画像の使用範囲（クロップ）を別々に保持
- `✂️ 範囲編集` 画面を追加
- 範囲枠をドラッグ・四隅リサイズ可能
- 右上腕 / 右前腕 / 右手などへ同じ元画像を一括共有可能
- JSON上では元画像を `imageSources` に1回だけ保持し、各ボーンから参照

## v35 主な変更
- 画像範囲編集で元画像を -180〜180° 回転、左右反転、上下反転してから範囲指定可能
- 適用時にボーンごとの範囲を透過PNG断片へ変換するため、同じ元画像を共有しても各部位だけが表示される
- 1枚の胴体画像を「胸・腹・腰」、1枚の腕画像を「上腕・前腕・手」のように分割可能
- 保存メニューから、現在フレームのボーン範囲・関節・部位名を示す「素材作成ガイドPNG」を出力可能

## v36 主な変更
- `〰 連続メッシュ` を追加
- 右上腕 → 右前腕 → 右手など、親子接続されたボーン列へ1枚の画像を途切れず割り当て可能
- 画像上の制御点をドラッグして、画像内で関節に相当する位置を指定
- ボーンを曲げると画像を短冊状の三角形メッシュへ分け、関節列に沿って連続変形
- 元画像側の太さ、表示側の太さ、曲線の滑らかさを調整可能
- 連続メッシュ設定は `project.meshBindings` に保存され、ブラウザ下書きとソースJSONの再読込に対応
- ボーン表示と画像表示を別々にON/OFF可能

## v37 主な変更
- 連続メッシュを右腕・左腕・右脚・左脚・胴体などの「交換パーツスロット」として保存
- 画像を差し替えても、接続ボーン列・メッシュ範囲・変形設定を維持
- 関節間へ中間点を追加し、中心位置と左幅・右幅を点ごとに調整可能
- 画像上の中心点と左右境界ハンドルを直接ドラッグ可能
- メッシュ画像ごとに左右反転・上下反転・角度を保存
- プロジェクト共通の基準ポーズを保存し、任意フレームへ復元可能
- 基準ポーズの輪郭・関節・中心線を示す交換パーツ用素材ガイドPNGを出力

## v38 主な変更
- 新規作成では通常2D／ドット2Dのそれぞれに横向き型と正面型を用意
- ドット2Dリグは15ボーンで、頭・体・腰、左右の上腕・腕・手、左右の太腿・すね・足首を持つ。交換画像は6パーツのまま連続変形
- 保存メニューから、組み立て済みキャラクターと実際の分解パーツを並べた「交換パーツ作画見本」を表示
- シアンの接続部を、回転時の隙間を防ぐ重なり代として明示
- 頭・胴体・左右腕・左右脚の、そのまま読み込める個別透過PNG例を用意
- 線と関節座標だけのPNGは、作画見本ではなく補助データへ移動

## ローカル保存と編集対象
- 起動時に `src/data/motion/boneMotionProjects.json` の保存済みモーション一覧を表示
- 「通常2D・横向き」は左右のつま先を含む19ボーン、「通常2D・正面」は17ボーン・1フレームの初期状態から開始
- 保存メニューの「ソースJSONへ保存」で、選択中のモーションを追加または上書き
- ブラウザの自動保存は作業中バックアップとして別に保持
- 画像範囲編集では、画像上端の角度ヘッダーをドラッグしてリアルタイム回転
- 画像範囲のX位置・W横幅は、この画像を使うチェック済み全部位で同じ値を共有。数値入力、枠移動、左右ハンドルのドラッグに対応

## 起動
リポジトリ直下で `npm run dev:client` を実行し、`/2d_bone_editor_split/` を開いてください。ソースJSONへの保存はViteのローカル開発APIを使用します。

交換パーツ画像は `part_templates/README.md` を参照してください。
