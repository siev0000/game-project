更新基準: v38 split

- 共通ボーン構造で複数キャラクター向けモーションを作成
- ボーン追加 / 複製 / 削除 / 親子接続
- 回転 / 移動 / 全体移動
- フレーム追加 / 複製 / 削除
- フレームごとのレイヤー順
- 画像セット、位置・拡大・角度・反転・不透明度調整

- ボーン表示と画像表示を別々に切り替え

## v36 連続メッシュ仕様
部位分割とは別方式。`project.meshBindings` の1設定が、1枚の元画像と接続されたボーン列をまとめて管理する。

標準人型では以下の列を候補にする。
- 右上腕 → 右前腕 → 右手
- 左上腕 → 左前腕 → 左手
- 右大腿 → 右すね → 右足
- 左大腿 → 左すね → 左足
- 腰 → 腹 → 胸 → 首

任意ボーンでも、親から子へ途切れず接続されている直列部分を候補にできる。離れたボーンや分岐をまたぐ一括指定は行わない。

### 操作
1. 対象列に含まれるボーンを選択
2. INSPECTORの `〰 連続メッシュ` を開く
3. 接続ボーン列を選ぶ
4. 1枚の画像を選択
5. 画像上の点をドラッグし、各関節と先端の位置を合わせる
6. 元画像の太さ、表示側の太さ、曲線の滑らかさを調整
7. 適用

適用したボーン列の通常画像割り当ては解除される。連続メッシュを削除するときは、同じ画面の `連続メッシュを削除` を使う。

### 保存形式
- `sourceId`: `project.imageSources` 内の共有元画像
- `boneIds`: 親子順のボーンID列
- `controlPoints`: 元画像上の関節位置（正規化座標）
- `sourceWidth`: 元画像から使用する帯の太さ
- `targetWidth`: ボーンに沿って表示する太さ
- `smoothness`: 曲線を分割する細かさ

描画時は元画像を三角形の帯へ分割し、現在フレームのボーン姿勢から作った曲線へ写像する。画像を部位ごとに切らないため、肘や膝を曲げても境界が途切れにくい。

## v37 交換パーツと細分化
連続メッシュは `partSlot` を持つ。標準スロットは `right_arm`、`left_arm`、`right_leg`、`left_leg`、`torso`。画像を選び直しても同じメッシュ設定を上書きするため、ポーズや範囲を作り直さず立ち絵の部品だけ交換できる。

制御点はボーン関節数に固定しない。関節間へ中間点を追加でき、各点は以下を持つ。
- `u` / `v`: 元画像上の中心位置
- `t`: 接続ボーン列上の位置
- `leftWidth`: 中心線から左境界までの幅
- `rightWidth`: 中心線から右境界までの幅

中心点は緑、左右境界は黄色のハンドルとして画像上で直接動かす。左右幅を別々に設定できるため、肩だけ太い、肘を絞る、手首側を広げるなどの輪郭指定が可能。

反転と回転は元画像データを書き換えず、メッシュ設定側の `flipX`、`flipY`、`rotation` に保存する。

## 基準ポーズ
`project.meta.referencePose` に画像作成用の共通姿勢を保存する。新規標準人型では初期フレームが基準。メッシュ編集画面から現在フレームを新しい基準にでき、別フレームを基準姿勢へ戻せる。

「素材ガイドPNG」は選択中の接続列について、基準姿勢の外周、中心線、関節位置、部位名を768×768pxで出力する。交換画像はこのガイドへ重ねて透過画像として作成する。

## v38 初期リグと作画見本
- `standard_2d`: 横向きは左右のつま先を含む19ボーン、正面は17ボーン。上腕・前腕・手、太腿・すね・足（横向きはつま先まで）を細かく制御する通常2D向け。
- `pixel_simple`: 15ボーン。頭、体、腰、左右の上腕・腕・手、左右の太腿・すね・足首を持つドット2D向け。正面型と横向き型を新規作成時に選べる。交換画像は6パーツのまま、腕・脚・胴体の内部を連続メッシュで曲げる。

作画時は `part_templates/reference` の実物見本を最初に見る。左が組み立て後、右が交換パーツ。シアン部分は隣接パーツの下へ差し込む重なり代。

`part_templates/examples` には頭・胴体・左右腕・左右脚を個別の透過PNGとして用意した。腕と脚は接続順に縦へまとめてあり、連続メッシュ画面へそのまま読み込める。

`part_templates/technical` の単色線画像とmanifestは座標確認・自動割り当て用で、作画見本には使わない。

## v34 画像仕様
元画像は `project.imageSources` に保存する。

各ボーンは以下を持つ。
- `imageSourceId`: 参照する元画像
- `imageCropX`
- `imageCropY`
- `imageCropW`
- `imageCropH`

元画像は `imageSources[].cropRotation`、`cropFlipX`、`cropFlipY` で回転・左右反転・上下反転してから範囲指定できる。
範囲を適用すると、回転後の画像から各ボーン用の透過PNG断片を生成して `imageFragmentData` に保持する。これにより、共有元画像の全体が各ボーンへ重なって表示されない。

Crop値は 0.0〜1.0 の正規化値。
そのため同じ元画像を、
- 右上腕
- 右前腕
- 右手
の3ボーンで共有し、それぞれ別範囲を表示できる。

同様に、1枚の胴体画像を「胸・腹・腰」に共有し、上部・中央・下部の3範囲へ分けて使用できる。

### 操作
1. ボーンを選択
2. `画像セット`
3. 画像を選ぶ
4. `✂️ 画像範囲編集` が開く
5. 「この画像を使うボーン」で共有先をチェック
6. 「編集するボーン」を切り替える
7. 黄色枠で各ボーンの使用範囲を指定
8. 適用

### 素材作成ガイド
保存メニューの「素材作成ガイドPNGを出力」は、現在フレームのボーン形状・部位名・関節位置を1枚のPNGへ書き出す。描画用の元絵を作る際に、各部位をどの位置と大きさへ描くか確認するための補助画像。

## 注意
現状は画像をJSON内へDataURLとして保存するため、大きな画像を多数登録するとlocalStorage容量に達する可能性がある。
共有画像方式にしたため同じ画像をボーンごとに重複保存する問題は軽減されるが、将来的にはIndexedDB化する。
