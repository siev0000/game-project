# 交換パーツ画像テンプレート

ボーンエディタの「交換パーツ見本PNG一式を出力」で生成した見本です。

## 最初に見る画像

- `reference/standard_2d_modular_reference.png`: 通常2D用。組み立て後と、実際の頭・胴体・腕・脚パーツを並べた作画見本。
- `reference/pixel_simple_modular_reference.png`: 15ボーンのドット2D用。交換画像は腕・脚を1画像に保ち、内部の3ボーンで曲げる作画見本。

シアン部分は関節の重なり代です。回転したときに隙間が出ないよう、この部分を隣のパーツの下へ差し込みます。

## 座標確認用の補助データ

- `technical/pixel_simple/`: ドット2D簡易リグ用の関節座標とmanifest。
- `technical/standard_2d/`: 通常2D標準リグ用の関節座標とmanifest。

各パーツには2種類あります。

- `*_guide.png`: 方眼、中心線、関節位置を確認する作画ガイド。
- `*_sample.png`: メッシュへの読み込み確認だけに使う単色の仮パーツ。

`technical` の画像は作画見本ではありません。キャラクターの輪郭は `reference` の実物見本を基準にします。

## そのまま読み込める個別PNG例

- `examples/pixel_simple/`: 128px基準の頭・胴体、128×256pxの左右腕・左右脚。
- `examples/standard_2d/`: 512px基準の頭、512×1024pxの胴体・左右腕・左右脚。

腕は肩側から手側、脚は股関節側から足側の順に1枚へまとめています。各部位のシアン接続部は互いに重なるよう合成済みです。

## 作画ルール

1. `guide.png` と同じキャンバスサイズで新しい透過画像を作る。
2. 黄色い横線・点を関節位置として、外周の内側へパーツを描く。
3. 完成画像では方眼、中心線、関節線を消す。
4. キャンバスを切り抜いたり拡大縮小したりせず、そのままPNGで保存する。
5. 対応するパーツスロットの画像を「画像を選択・差し替え」から選ぶ。

`*_part_manifest.json` にはキャンバスサイズ、対象ボーン、正規化された関節点を保存しています。将来のパーツ画像ライブラリでは、この値を読み取って自動割り当てできます。
