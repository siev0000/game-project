# UI設計まとめ（現時点版）

## 基本方針
- **基本画面 = エリア背景 + 上部エリア情報 + 下部パーティバー**
- 施設や詳細画面は **モーダル表示** で呼び出す
- 拠点 / ダンジョン / 戦闘 で中央エリア表示を切り替える

---

## 画面構成

### 上部（ヘッダー / エリア情報バー）
- 現在地（エリア名 / 部屋名）
- 時間帯（朝 / 昼 / 夕 / 夜）
- 天気（晴れ / 雨 / 雪 / 砂嵐 / 吹雪…）
- 所持金
- 状態異常アイコン（毒 / 出血 / 石化など）

---

### 中央（メイン表示エリア）
- **拠点画面**  
  - 背景：街や村のエリア画像
  - **施設ボタン**（クリックでモーダル表示）  
    - ステータス/編成・装備  
    - ショップ  
    - ギルド  
    - 宿屋  
    - 教会  
    - 鍛冶屋  
    - クエスト/ログ  
    - システム設定  

- **ダンジョン探索画面**  
  - 背景：ダンジョン画像
  - 操作UI：進む / 戻る / 左 / 右
  - 遭遇判定 → イベント / 戦闘 / アイテム / 罠

- **戦闘画面**  
  - 専用レイアウト（ターン制バトルUI）
  - パーティと敵のHP/MP/ST表示
  - 行動枠（A / S / Q）

- **散策ポイント画面**  
  - 背景：街や村の一部エリア  
  - **役割** : 街を散歩してちょっとしたイベントが発生する程度の要素  
  - 小規模イベントや雰囲気演出に利用  
  - メイン機能（売買や蘇生など）は持たない  


---

### 下部（パーティステータスバー）
- **横スクロール対応**
- 各キャラの簡易情報
  - アイコン
  - 名前
  - Lv
  - HPバー
  - MPバー
  - STバー

---

## モーダル一覧
- ステータス / 編成・装備  
  - 能力値・技能値・耐性・装備・スキル  
- ショップ（売買UI）  
- ギルド（クエスト受注・報告）  
- 宿屋（回復・時間経過）  
- 教会（蘇生・状態異常回復）  
- 鍛冶屋（強化・修理・クラフト）  
- クエスト/ログ（進行度確認）  
- システム設定（音量・UIサイズなど）

---

## 表示切替ルール
- **拠点画面** → 施設ボタン表示  
- **ダンジョン画面** → 探索操作ボタン表示  
- **戦闘画面** → 戦闘専用UI表示  
- **上部エリア情報バー / 下部パーティバー** は常時固定表示

# 雲と背景ルール仕様

## 雲の配置ルール

### レイヤー構造
- **遠景雲** : 大きめ、動き遅い、透明度高め（背景感）
- **中景雲** : 中サイズ、普通の速度
- **近景雲** : 小さめ、動き速い、透明度低め（前を横切る感じ）
- → z-index を分けて3レイヤーにすることで立体感を演出

### 配置方向
- 基本は「左 → 右」に流れる
- 稀に「右 → 左」の逆流を混ぜて自然感を出す
- 近景ほど速く流れる設定

### 基準パターン
- **パターンA** : 上部に多い
- **パターンB** : 中央に密集
- **パターンC** : 下寄りに数枚  
※ 各パターンにランダム補正（位置±50px、速度±20%）を追加

### 天気ごとの雲パターン（昼の例）
- 晴れ : 上部1〜2枚、透明度70〜90%
- 曇り : 中央4〜6枚、灰色、透明度40〜60%
- 雨   : 下寄り5〜7枚、暗灰色、透明度50%
- 雪   : 中央4〜6枚、白灰色、透明度60%
- 吹雪 : 中央+下に6〜7枚、透明度30〜50%

### 雲のゾーン（例: 4分割）
1. 上層（遠景雲）: 大きめ、動き遅い、透明度高め  
2. 中上層（中景雲）: 中サイズ、速度普通、透明度中間  
3. 中下層（中景雲）: 中サイズ、速度普通、透明度中間  
4. 下層（近景雲）: 小さめ、動き速い、透明度濃いめ（前景感）

---

## 背景レイアウト
- 下6割 = エリア画像（森・街・山など）
- 上4〜5割 = 空（時間帯・天気によって変化）
- 空は複数ゾーンに分けて雲を配置し、ランダム性を持たせる

---

## 星の扱い
- 星は別画像（PNG/WebP透過）
- サイズ: 500px 四方程度
- 方角ごとに種類を用意（北/東/南/西）
- 夜のみ表示（屋外限定）
- 方角固定 or ランダムで星座切替

---

## 光の演出
- CSSグラデーションのオーバーレイを使用
- 朝: オレンジ系  
- 昼: なし  
- 夕方: 赤紫系  
- 夜: 青〜紺系  
- 稲光や光の筋は追加レイヤーで実装

---

## Excelエリアデータ
- 屋内外 : 「内」/「外」
- 種別   : ダンジョン / 街 / 村 / 自然 など
- デフォ天気 : 晴れ / 曇り / 雨 / 雪 / 砂嵐 / 吹雪
- デフォ時間帯 : 朝 / 昼 / 夕方 / 夜
- 内包施設 : ショップ / 教会 / 宿 / 鍛冶屋 / ギルド など

---

## 施設ごとの機能
- **ショップ** : 武器/防具/消耗品/特殊品の売買
- **宿屋** : HP/MP/ST回復、状態異常治癒、時間経過
- **教会** : 蘇生、状態異常解除、寄付（評判・信仰度）
- **鍛冶屋** : 強化、修理、クラフト、エンチャント
- **ギルド** : クエスト受注・報告、ランク確認、評判管理
- **城/領主館** : ストーリー進行、NPC加入、イベント解放
- **市場/闇市** : 限定商品・違法商品・時間制商品

---

## 散策ポイント管理ルール
- **固定カテゴリ**（全エリア共通）
  - 広場 / 市場 / 裏路地 / 城門
- **追加カテゴリ**（地域特色に応じて付与）
  - 港、鉱山入口、王城前、魔法学院、鍛冶場、闇市、廃墟 など

| 港町     | 街   | 広場, 市場, 裏路地, 城門 | 港, 漁港の倉庫     | ショップ, 宿屋, 教会              |
| 山村     | 村   | 広場, 市場, 裏路地, 城門 | 鉱山入口, 鍛冶場   | 宿屋, ショップ                    |
| 荒廃都市 | 街   | 広場, 市場, 裏路地, 城門 | 闇市, 廃墟         | 宿屋, 闇市                        |

## イベントシート仕様
- Excelで管理
- 項目例:
  - ID / イベント名 / 発生場所（散策ポイント）
  - 日時（朝/昼/夕/夜）
  - 条件（ギルドランク、治安、クエスト進行など）
  - 発生回数（1回限り / 繰り返し）
  - 内容 / 報酬

### 判定フロー
1. プレイヤーが散策ポイントを選択  
2. イベントシート条件と照合  
3. 一致 → イベント発生  
4. 不一致 → 通常散策結果（会話や発見など）
