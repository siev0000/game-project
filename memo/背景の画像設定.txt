【雲の配置ルール（概要）】

■ レイヤー構造
- 遠景雲 : 大きめ、動き遅い、透明度高め（背景感）
- 中景雲 : 中サイズ、普通の速度
- 近景雲 : 小さめ、動き速い、透明度低め（前を横切る感じ）
※ z-index を分けて 3 レイヤーにすると立体感が出る

■ 配置方向
- 基本は「左 → 右」に流れる
- 稀に「右 → 左」の逆流を1枚入れると自然感
- 近景ほど速く流れる設定

■ 基準パターン（例）
- パターンA : 上部に多い
- パターンB : 中央に密集
- パターンC : 下寄りに数枚
※ そこにランダム補正を入れる（位置±50px、速度±20%）

■ 天気ごとの雲パターン（昼の例）
- 晴れ : パターンA（上部1〜2枚）、透明度70〜90%
- 曇り : パターンB（中央4〜6枚）、灰色、透明度40〜60%
- 雨   : パターンC（下寄り5〜7枚）、暗灰色、透明度50%
- 雪   : パターンB（中央4〜6枚）、白灰色、透明度60%
- 吹雪 : パターンB+C（中央と下に6〜7枚）、透明度30〜50%

【背景レイアウトの基本】
- 画面の下6割 → エリア画像（森・街・山など）
- 画面の上4〜5割 → 空（時間帯・天気で変化）

【空の構成】
- 空部分を縦に複数ゾーン（層）に分けて雲を配置する
- 各ゾーンにはランダムに雲を割り当てるが、ゾーンごとの特徴を固定する

【ゾーン例（4分割）】
1. 上層（遠景雲）
   - 大きめ、動き遅い、透明度高い（薄め）
2. 中上層（中景雲）
   - 中サイズ、速度普通、透明度中間
3. 中下層（中景雲）
   - 中サイズ、速度普通、透明度中間
4. 下層（近景雲）
   - 小さめ、動き速い、透明度濃いめ（前景感）

【雲の方向】
- 基本は「左 → 右」に流れる
- 稀に「右 → 左」の逆流を混ぜると自然感
- 下層ほど速く流すと立体感が増す

【全体のルール】
- 雲の配置は「ゾーンごとに基準パターンを持ちつつランダム補正」
- X座標はランダム、Y座標はゾーン範囲内でランダム
- 回避・透明度にもランダム補正を少し入れる
- これにより「毎回違う配置になるが、全体のバランスは崩れない」


【背景構成】
- 下6割 = エリア画像（locations）
- 上4〜5割 = 空（sky）
- 空は天気・時間帯・星で動的に変化

【星の扱い】
- 星は別画像 (PNG/WebP透過)
- 500px 四方程度
- 方角ごとに種類を用意（例: 北/東/南/西）
- 夜のみ表示、屋外限定
- 方角固定で出す or ランダムで星座切替

【光の演出】
- CSSグラデーションのオーバーレイのみ使用
- 朝: オレンジ系
- 昼: なし
- 夕方: 赤紫系
- 夜: 青〜紺系
- 稲光や光の筋は追加レイヤーとして出す

【保存場所 (src/assets/images/)】
sky/        ← 雲・星・オーバーレイ  
   ├── clouds/  
   ├── stars/  
   └── overlay/  
locations/  ← エリア背景（森、街、砂漠、雪原など）

【Excelエリアデータ】
- 屋内外 : 「内」「外」
- 種別   : 「ダンジョン」「街」「村」「自然」など
- デフォ天気 : 晴れ / 曇り / 雨 / 雪 / 砂嵐 / 吹雪
- デフォ時間帯 : 朝 / 昼 / 夕方 / 夜
- 内包施設 : 「ショップ」「教会」「宿」「鍛冶屋」「ギルド」など複数可

【施設ごとの機能】
- ショップ : 売買（武器/防具/消耗品/特殊ショップ）
- 宿屋     : HP/MP/ST回復、状態異常治癒、時間経過
- 教会     : 蘇生、状態異常解除、寄付（評判・信仰度）
- 鍛冶屋   : 強化、修理、クラフト、エンチャント
- ギルド   : クエスト受注/報告、ランク確認、評判管理
- 城/領主館: ストーリー進行、NPC加入、イベント解放
- 市場/闇市: 限定商品や違法商品、時間制商品

【散策】
【散策ポイント管理ルール】

■ 基本構成
- エリアには「固定カテゴリ」と「追加カテゴリ」が存在する
- 固定カテゴリは全ての町や村に共通
- 追加カテゴリは地域の特色を表す要素として自由に設定

■ 固定カテゴリ（全エリア共通）
- 広場   : NPCが集まり、会話・噂・小イベントが起きる
- 市場   : 商人・物売り、サブイベント（盗難・取引など）
- 裏路地 : 治安が悪い場所、盗賊や裏取引、危険イベント
- 城門   : 街の出入口、フィールドや他エリアへの移動

■ 追加カテゴリ（必要に応じて付与）
- 港       : 港町限定、漁師・船旅・闇取引
- 鉱山入口 : 山村限定、採掘・鉱石イベント・モンスター遭遇
- 王城前   : 大都市限定、王族や騎士団イベント
- 魔法学院 : 特殊都市限定、魔法関連イベント・クエスト
- 鍛冶場   : 工房や鉱山村限定、武具製作や強化イベント
- 闇市     : 治安が悪い都市限定、違法取引や特殊アイテム販売
- 廃墟     : 荒廃都市限定、危険な探索や戦闘イベント

■ Excel管理例
| 町名     | 種別 | 固定カテゴリ             | 追加カテゴリ       | 内包施設                     |
|----------|------|--------------------------|-------------------|------------------------------|
| 中央都市 | 街   | 広場, 市場, 裏路地, 城門 | 王城前, 魔法学院   | ショップ, 宿屋, 教会, 鍛冶屋, ギルド |
| 港町     | 街   | 広場, 市場, 裏路地, 城門 | 港, 漁港の倉庫     | ショップ, 宿屋, 教会         |
| 山村     | 村   | 広場, 市場, 裏路地, 城門 | 鉱山入口, 鍛冶場   | 宿屋, ショップ               |
| 荒廃都市 | 街   | 広場, 市場, 裏路地, 城門 | 闇市, 廃墟         | 宿屋, 闇市                   |

■ ルールまとめ
- 固定カテゴリによりUI・基本処理を統一
- 追加カテゴリで町ごとの個性を表現
- Excel上では「固定カテゴリ」「追加カテゴリ」を列として管理
- 内包施設は施設シートの内容と連動可能


【イベントシート】
- イベントを別シートで管理
- 項目例:
  - ID
  - イベント名
  - 発生場所（散策ポイント）
  - 日時（朝/昼/夕/夜）
  - 条件（ギルドランク、治安、特定クエスト進行など）
  - 発生回数（1回限り / 繰り返し）
  - 内容
  - 報酬
- 判定の流れ:
  1. プレイヤーが散策ポイントを選ぶ
  2. イベントシートの条件と照合
  3. 条件一致 → イベント発生
     条件不一致 → 通常散策結果（会話や発見）
