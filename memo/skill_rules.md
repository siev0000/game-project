# スキル表記ルール

## 1. 基本カラム
```
Lv | スキル名 | ルビ | 系統 | 種別 | HP消費 | MP消費 | ST消費 | 効果 | 表示テキスト
```

---

## 2. 種別ごとの書き方

### A（行動スキル：攻撃・回復）
- **攻撃**  
  ```
  攻撃手段:◯◯ 属性+数値 or 属性倍+◯% 射程:◯ 範囲:◯◯ 追加威力:能力 判定:能力
  ```
- **回復**（対象を選んで使用する場合は基本A型）  
  ```
  回復+数値 判定:能力
  ```
- 吸収型  
  - 吸血：出血ダメージに応じて回復 → `吸血_10`  
  - ドレイン：与ダメージ全体から回復 → `ドレイン_10%`  

---

### S（強化スキル：自己強化・自動回復）
- **行動を使わない強化・回復はS**  
- 書式  
  ```
  効果時間◯t 上昇値や回復量
  ```
- 例  
  ```
  効果時間3t 攻撃+10 回避+10
  効果時間2t 回復+10 判定:魔力
  ```

---

### Q（速攻スキル：即効系・反応行動）
- Sと同様だが即時発動を前提にする。  
- 例  
  ```
  効果時間3t 光耐性+20 命中+10 隠密+15
  ```

---

### P（パッシブ：恒常効果）
- 書式  
  ```
  ステータスや耐性補正のみを記載（常時効果: は不要）
  ```
- 例  
  ```
  攻撃+15 防御+10 回避+10
  闇耐性+25 光耐性-10
  ```

---

## 3. 属性・耐性表記
- 基礎威力上昇 → `闇+10`  
- 倍率上昇 → `闇倍+20%`  
- 無効化 → `闇耐性+100`  

---

## 4. 範囲指定
- 書式：`範囲:単体 / 縦 / 横 / 全体 / 列指定 / 周囲`  
- 「周囲」は敵味方含む  

---

## 5. 系統表記
- 系統は自由でOK（例：血 / 闇 / 感知 / 再生 など）  

---

## 6. 行動と対象の基本ルール
- **回復は基本A型**（対象を選んで行動するため）  
- **再生など行動を使わない場合はSやQ型**  
- **対象が明記されていない場合は、基本「選択相手」になる**  

---
## 7. 条件の扱い

- **条件は最小限にする**  
  不要に条件を増やすと仕様が複雑になりすぎるため、必要な場合のみ記載する。

- **環境や状況による条件**  
  例: `条件:夜`、`条件:光環境`

- **特定スキルに依存する場合**  
  例: `条件:吸血衝動 攻撃+10`  
  → 吸血衝動を使用した時のみ攻撃+10の補正を得る。

- **条件系統は使用しない**  
  系統条件は仕様量が増えるため不採用。スキル名で限定すれば十分。

---

## 8. 能力値の限定

- **ゲーム詳細.txtに記載の能力値・技能値のみ使用する**  
  それ以外の独自数値は作らない。  

- 例: 攻撃、防御、魔力、精神、速度、命中、HP、MP、ST、隠密、感知、軽業、威圧 など。  

- スキルの強化や条件判定も、必ずこの範囲の数値を参照する。
