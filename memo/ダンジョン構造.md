# 探索システムまとめ

## 探索システムの基本構成

### ワールドマップ
- マップ選択式
- 世界地図/地域マップから行き先を選ぶ
- 各エリアの情報（名前、種別、推奨Lv、施設など）を表示
- 移動で時間が経過する（例：半日）
- 移動中に遭遇テーブルを判定（盗賊、野生動物、商人など）

### ダンジョン探索
- 画面遷移式（Twine風）
- 「進む / 戻る / 左へ / 右へ」などの選択肢で移動
- 移動ごとに遭遇判定 / アイテム発見 / 罠判定 / イベント発生
- 移動ごとに時間経過（1移動 = 数分）

### 時間管理
- ワールドマップ移動 = 大きく時間が進む（半日など）
- ダンジョン探索 = 移動ごとに小刻みに時間が進む
- 朝・昼・夕・夜で敵やイベント内容が変化
- 時間帯は背景（空の色・星表示）や敵の出現リストに影響する

### Excel管理
- エリアシートに「ダンジョンタイプ（linear / structure）」を追加
  - `linear` = 単純進行型（階層数で管理）
  - `structure` = 構造型（ノード・遷移で管理）
- 遭遇・出現敵・探索アイテム・罠を文字列で記載して管理
---

## ダンジョンタイプ

### 1. 単純進行型（linear）
- 踏破数を設定
- 進む/戻るのみ
- 指定数進むとボス部屋へ到達
- Excel管理は「階層数」でOK

### 2. 構造型（structure）
- 分岐・隠し通路・宝物庫などあり
- 選択肢で移動（進む/戻る/左/右など）
- Excel管理は「ノードID」と「遷移先」で構造を作る
---

## 踏破数
- ダンジョンごとに「踏破必要数」を設定
- 1移動 = 踏破数+1
- 踏破数が上限に達するとボス部屋 or 脱出地点へ
- 踏破数進行度に応じて遭遇率を上げる/下げる調整も可能
---

## 遭遇テーブル
- 書式 : `イベント名:確率`
- 1〜100の乱数を振り、区間内に入れば発生
- 例:
  ```
  接敵:20, 罠:5, 強敵:1, アイテム:15
  ```
- 区間外は「何も起きない」
- イベントは複数設定可能（商人出現、特殊イベントなど）
---

## 出現敵テーブル
- 書式 : `(敵名×数, 敵名×数...):比率`
- 遭遇で「接敵」イベントが出た際に参照
- 例:
  ```
  (ゴブリン×2, コウモリ×1):40, (骸骨×3):60
  ```
- 合計100でなくても比率処理可能
- 特殊枠「強敵」は別リストでレア敵を定義可能
---

## 探索アイテム
- 書式 : `アイテム名:技能名_数値`
- 技能値が必要値以上なら入手成功
- 複数記載可
- 例:
  ```
  力核:鑑定_30
  銀鉱石:装置_30, 宝箱:技術_50
  ```
- アイテム取得時の「消費」や「再取得不可」なども別列で設定可能
---

## 罠
- 書式 : `罠名:技能名_数値`
- 技能判定に成功すれば回避、失敗で効果発動
- 例:
  ```
  落とし穴:感知_25
  毒矢:回避_30
  石落とし:軽業_40
  ```
- 効果（ダメージ、状態異常など）は別列で管理可能
---

## 処理フロー
1. プレイヤーが移動を選択 → 踏破数+1  
2. 遭遇テーブルでイベント判定  
3. 接敵なら → 出現敵テーブルで敵グループ決定  
4. アイテムなら → 探索アイテムリストで技能判定  
5. 罠なら → 罠リストで技能判定（失敗で効果）  
6. 何もなしなら進行のみ  
7. 踏破数が上限に達したらボス部屋へ
